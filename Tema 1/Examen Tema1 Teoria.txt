    }

Escribe tres llamadas diferentes que demuestren:
- uso de argumentos posicionales; print(crear_tarea("Patata", 3, True))

La funcion devolvera un diccionario que almacenara con la palabra clave titulo, el titulo que le pasemos por parametro, en la palabra clave prioridad almacenara el valor prioridad que le pasemos por parametro(a no ser que no le demos nada, en cuyo caso nos dara 3; su valor por defecto) y en la palabra clave urgente almacenará un valor true o false que le demos por parametro(A no ser que no le demos nada, en cuyo caso lo declarará siempre como false)

A5. Ámbito de variables
Explica qué diferencia hay entre variables locales y globales. ¿Qué hace global?
Una variable local es basicamente un tipo de variable que esta declarada para un scope en concreto, mientras que una variable global abarca y es visible por todo el programa entero
la palabra reservada global en python sirve para decirle que fuera del scope en el que se encuentra una variable hay una variable con la misma etiqueta que es a la que queremos modificar, no crear una variable local

¿Por qué una función puede modificar una lista recibida como argumento sin utilizar global?
Porque cuando la pasas por parametro, python sabe que estas haciendo referencia a la lista que has pasado por parametro y en vez de crear un objeto nuevo, modifica el que le has pasado
