    @property permite crear un pseudo getter para la clase y @precio.setter fijar una serie de parametros de control en el setter de nuestras funciones

    @property
    def precio(self) -> float: #Es como un getter para la clase
        return self._precio #para evitar llamadas recursivas

    @precio.setter #El setter de la clase con control de flujo
    def precio(self, valor) -> None:
        
        if valor < 0:

        self._precio = valor

Pregunta 8 — Composición y agregación
Valor: 0,5 puntos.
Imagina que tenemos una clase Tarea y una clase Proyecto que contiene varias tareas.
Considera estas dos implementaciones:

Implementación A = agregación
class Proyecto:
    def __init__(self, nombre: str):
        self.nombre = nombre
        self.tareas = []

    def agregar_tarea(self, tarea: Tarea) -> None:
        self.tareas.append(tarea)


Implementación B = Composición
class Proyecto:
    def __init__(self, nombre: str):
        self.nombre = nombre
        self.tareas = []

    def crear_tarea(self, titulo: str) -> None:
        nueva_tarea = Tarea(titulo)
        self.tareas.append(nueva_tarea)


Responde:
a) ¿Cuál de las dos implementaciones representa más directamente una agregación y cuál una composición?
b) Explica la diferencia conceptual entre ambas relaciones. ¿La diferencia consiste simplemente en que las tareas sean obligatorias u opcionales?

   agregación se encarga de agrupar cosas que pueden existir independientemente de la clase, mientras que composición considera como suyas las partes que procesa y por tanto el ciclo de vida de estas esta vinculado a la propia clase
